How to use this page

3-pass revision strategy
Pass 1 (this week, 1 day per section). Open the section cheatsheet → read top to bottom once → drill that section in the mixed bank or a recent mock → return to the cheatsheet and re-read only the bits you missed.
Pass 2 (penultimate week, 2 days total). Use the consolidated revision pack as the spine. Read every section cheatsheet again, tables only, skipping bullets you already know. Re-attempt one fresh full-length mock.
Pass 3 (exam week). The two debriefs (MET Mock 1, NIMHANS Mock 1), plus the EPUB bundle for the bus. Re-read only the red TRAP boxes and tables. Do not start new topics.
