How to use this page

3-pass revision strategy
Pass 1 (this week, 1 day per section). Open the section cheatsheet → read top to bottom once → drill that section in a recent mock → re-read only the bits you missed.
Pass 2 (penultimate week). Use the consolidated revision pack as the spine. Re-read every cheatsheet, tables only, skip what you know. Re-attempt one fresh mock.
Pass 3 (exam week). The two debriefs (MET Mock 1, NIMHANS Mock 1) plus the EPUB for the bus. Re-read only the red TRAP boxes and tables. No new topics.
