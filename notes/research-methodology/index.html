1. Types of Data (Levels of Measurement)

Stevens (1946) gave us the four levels. Knowing the level dictates which statistical test you can use.

LevelPropertiesExampleAllowed stats
NominalCategories only, no orderSex, blood group, religion, diagnosis (yes/no)Mode, frequency, chi-square
OrdinalOrder, but unequal intervalsPain scale 0-10, Likert (agree/disagree), socio-economic classMedian, percentile, Spearman's rho, Mann-Whitney U
IntervalEqual intervals, no true zeroTemperature in °C, IQ, calendar yearsMean, SD, t-test, ANOVA, Pearson's r
RatioEqual intervals + true zeroHeight, weight, reaction time, ageAll of the above + geometric mean, ratios meaningful

Memory hook: NOIR = Nominal, Ordinal, Interval, Ratio (in increasing order of information).

2. Descriptive Statistics

Central Tendency (where the middle is)

  • Mean — arithmetic average. Sensitive to outliers. Use for symmetric/normal data.
  • Median — 50th percentile. Robust to outliers. Use for skewed data or ordinal data.
  • Mode — most frequent value. Only measure for nominal data. A distribution can be bimodal/multimodal.

Dispersion (how spread out the data is)

  • Range = max − min. Crude, sensitive to outliers.
  • IQR (Interquartile Range) = Q3 − Q1. Robust. Used in box plots.
  • Variance = mean of squared deviations from the mean. Units are squared.
  • Standard Deviation (SD) = √variance. Same units as the data. The default dispersion measure.
  • Standard Error of the Mean (SEM) = SD / √n. Dispersion of the sample mean, not of individuals. Always smaller than SD.
  • Coefficient of Variation (CV) = SD/mean × 100%. Compares variability across different scales.

Shape

  • Skewness — asymmetry. Positive skew = long right tail (mean > median > mode). Negative skew = long left tail (mean < median < mode).
  • Kurtosis — peakedness. Leptokurtic = tall, narrow peak (high kurtosis, fat tails). Platykurtic = flat. Mesokurtic = normal.

3. Distributions

Normal (Gaussian) Distribution

Bell-shaped, symmetric, mean = median = mode at center. Defined by μ and σ.

  • 68-95-99.7 rule: 68% within ±1 SD, 95% within ±2 SD (more precisely 1.96), 99.7% within ±3 SD.
  • z-score = (x − μ) / σ. Standardizes any value to the standard normal (μ=0, σ=1).
  • Central Limit Theorem (CLT): the sampling distribution of the mean approaches normal as n increases, regardless of the shape of the underlying population. Foundation of inferential statistics. Rule of thumb: n ≥ 30.

Other distributions you should recognize

  • t distribution — like normal but with fatter tails, shaped by degrees of freedom (df). Approaches normal as df → ∞.
  • Chi-square (χ²) — right-skewed, only positive values. Used for categorical data.
  • F distribution — ratio of two variances. Used in ANOVA and regression.
  • Binomial — discrete, two outcomes (success/failure) over n trials.
  • Poisson — count of rare events in fixed time/space (e.g., suicides per year, ER admissions per hour).

4. Inferential Statistics

Hypothesis Testing Framework

  1. State H₀ (null): no effect / no difference.
  2. State H₁ (alternative): there is an effect.
  3. Choose α (significance level), usually 0.05.
  4. Compute the test statistic and p-value.
  5. If p < α, reject H₀. If p ≥ α, fail to reject H₀.

Important: we never accept H₀, we only fail to reject it. Absence of evidence ≠ evidence of absence.

Errors

H₀ trueH₀ false
Reject H₀Type I error (α) — false positiveCorrect (power, 1−β)
Fail to reject H₀Correct (1−α)Type II error (β) — false negative
  • Type I (α) = saying there's an effect when there isn't. Standard cap at 0.05.
  • Type II (β) = missing a real effect. Standard target ≤ 0.20.
  • Power = 1 − β. Probability of correctly detecting a real effect. Convention: aim for 0.80.
  • Power increases when: n ↑, effect size ↑, α ↑ (more lenient), variability ↓, one-tailed test.

One-tailed vs Two-tailed

  • Two-tailed (default): tests whether the difference is non-zero in either direction. α split, 0.025 in each tail.
  • One-tailed: tests for difference in a specific direction. More power, but only if you have a strong a priori reason. Considered conservative practice to use two-tailed by default.

p-values

  • Probability of observing the data (or more extreme) if H₀ is true.
  • NOT the probability that H₀ is true. Common MCQ trap.
  • p < 0.05 = "statistically significant" (by convention, not by nature).
  • Statistical significance ≠ clinical/practical significance.

Confidence Intervals (CI)

  • Range of plausible values for the true population parameter.
  • 95% CI means: if we repeated the study many times, 95% of constructed CIs would contain the true value.
  • If 95% CI for a difference excludes 0, p < 0.05.
  • If 95% CI for a ratio (OR/RR) excludes 1, p < 0.05.
  • Wider CI = less precise estimate (small n or high variability).

Effect Size

  • Magnitude of the effect, independent of sample size.
  • Cohen's d for mean differences: 0.2 small, 0.5 medium, 0.8 large.
  • Pearson's r for correlation: 0.10 small, 0.30 medium, 0.50 large.
  • Eta squared (η²) / partial η² for ANOVA: 0.01 small, 0.06 medium, 0.14 large.
  • Odds Ratio (OR) / Relative Risk (RR) for case-control / cohort.

  3. Independence of observations
  4. Interval/ratio measurement

7. Sampling

Probability sampling (random, generalizable)

  • Simple random — every individual has equal chance. Lottery method.
  • Stratified random — divide population into strata (sex, age groups, etc.), then sample randomly within each. Ensures representation.
  • Cluster — divide into clusters (schools, villages), randomly select clusters, study everyone within. Cheaper for large geographic areas.
  • Systematic — every kth person from a list. k = N/n. Risk: periodicity in the list.
  • Multistage — combination (e.g., random districts → random schools → random students).

Non-probability sampling (less rigorous, often used in qualitative research)

  • Convenience — whoever is available. Most biased.
  • Purposive (judgmental) — researcher chooses based on expertise/criteria.
  • Quota — fill quotas (e.g., 50 men, 50 women) but not randomly.
  • Snowball — participants recruit other participants. Used for hidden/stigmatized populations.

Sample size — drivers

  • Larger when: smaller expected effect size, higher variability, lower α (e.g., 0.01), higher power required, multiple comparisons.
  • Pilot study or prior literature gives the variance estimate.
  • Common formulas use Cohen's tables, G*Power software.

By time

  • Cross-sectional — one time point. Cheap, no causation.
  • Longitudinal — same subjects over time. Causation possible. Risk: attrition (drop-out).
  • Cohort sequential — combines cross-sectional and longitudinal. Distinguishes age vs cohort effects.

9. Clinical Trial Phases & Design Features

PhasePurposeSample size
Phase 0Microdosing, exploratory pharmacokinetics~10-15
Phase ISafety, dose-finding, healthy volunteers (or patients for cancer drugs)20-100
Phase IIEfficacy + safety in target population100-300
Phase IIIConfirmatory efficacy, comparison vs standard. Required for licensing.1,000-3,000
Phase IVPost-marketing surveillance. Long-term effects, rare adverse events.Thousands+

Blinding

  • Single-blind — subject doesn't know group allocation.
  • Double-blind — subject AND researcher (assessor) don't know.
  • Triple-blind — also data analyst is blinded.
  • Open-label — no blinding. Used when blinding is impossible (surgery vs no surgery).

Other RCT design features

  • Placebo control — inert intervention to control for expectancy effects.
  • Active control — comparison vs current standard treatment (more ethical when one exists).
  • Crossover design — each subject receives both treatments in random order, separated by washout. Each subject is their own control. Cannot use for chronic/cure conditions.
  • Intention-to-treat (ITT) analysis — analyze subjects in their originally assigned group, even if they dropped out or switched. Preserves randomization, more conservative.
  • Per-protocol analysis — only analyze subjects who completed protocol. Inflates effect sizes.

10. Variables

  • Independent variable (IV) — manipulated or grouping variable. Cause.
  • Dependent variable (DV) — measured outcome. Effect.
  • Confounding variable — third variable associated with BOTH IV and DV; creates spurious associations. Control by randomization, matching, stratification, or statistical adjustment.
  • Mediator (intervening) — explains how IV affects DV. IV → Mediator → DV. (Stress → cortisol → immune suppression.)
  • Moderator — affects the strength or direction of the IV-DV relationship. (Therapy works better for women than men: sex moderates therapy → outcome.)
  • Extraneous variable — any variable other than IV that could affect DV. Becomes a confound if associated with IV.

11. Validity in Research

Different from validity of a test (which is in section 4 assessment). Here we mean validity of a study's conclusions.

TypeQuestionThreats

Trustworthiness criteria (Lincoln & Guba, 1985)

  • Credibility ≈ internal validity. Achieved by triangulation, member checking, prolonged engagement.
  • Transferability ≈ external validity. Thick description of context.
  • Dependability ≈ reliability. Audit trail.
  • Confirmability ≈ objectivity. Reflexivity, audit.

13. Mixed Methods

  • Combines qualitative + quantitative for a fuller picture.
  • Sequential explanatory: quant first, then qual to explain results.
  • Sequential exploratory: qual first to develop hypotheses, then quant to test.
  • Convergent (parallel): both done together, results compared.
  • Embedded: one supplements the other (e.g., qual interviews within an RCT).

14. Research Ethics

Foundational documents (memorize the order)

  1. Nuremberg Code (1947) — after Nazi medical experiments. First major ethics code. Voluntary consent absolute.
  2. Declaration of Helsinki (1964, last revised 2013) — World Medical Association. Ethics for medical research.
  3. Belmont Report (1979) — US, after Tuskegee syphilis study. Three principles below.
  4. CIOMS Guidelines — international ethics for biomedical research.
  5. ICMR Guidelines (India) — Indian Council of Medical Research, 2017 revision.

Belmont Principles (memorize these three)

  1. Respect for persons — autonomy, informed consent. Special protection for vulnerable groups.
  2. Beneficence — maximize benefits, minimize harm.
  3. Justice — fair distribution of risks and benefits. No exploiting vulnerable populations.

Informed consent — required elements

  • Purpose, procedures, expected duration
  • Risks and benefits
  • Alternative procedures
  • Confidentiality
  • Voluntary participation; right to withdraw without penalty
  • Contact info for questions

IRB / Ethics Committee

  • Reviews proposals before data collection.
  • Multidisciplinary: scientists + non-scientists + community member + lay person.
  • Categories of review: exempt (low risk, anonymous data), expedited (minimal risk), full board (greater than minimal risk).

Key ethical violations to know

  • Tuskegee syphilis study (1932-1972) — Black men denied treatment to study natural progression of syphilis. Led directly to the Belmont Report.
  • Milgram obedience experiment (1961) — deception, severe psychological distress.
  • Stanford Prison Experiment (1971, Zimbardo) — inadequate safeguards, role conflict (Zimbardo as researcher AND superintendent).
  • Little Albert (1920, Watson) — fear conditioning of an infant, no debriefing.
  • Willowbrook hepatitis study (1956-1970) — children with intellectual disabilities deliberately infected with hepatitis.

15. Critical Appraisal & Evidence Hierarchy

Evidence hierarchy (top = strongest)

  1. Systematic reviews / meta-analyses of RCTs
  2. Single well-designed RCT
  3. Cohort study
  4. Case-control study
  5. Cross-sectional / case series
  6. Case report
  7. Expert opinion / editorials

Tools (good to recognize)

  • CONSORT — reporting standard for RCTs
  • PRISMA — reporting standard for systematic reviews/meta-analyses
  • STROBE — reporting for observational studies
  • SPIRIT — reporting for trial protocols
  • COREQ — reporting for qualitative research

Diagnostic test stats (high-yield)

  • Sensitivity = TP / (TP + FN). True positive rate. Sensitive test rules OUT (SnNout).
  • Specificity = TN / (TN + FP). True negative rate. Specific test rules IN (SpPin).
  • PPV = TP / (TP + FP). Positive predictive value. Depends on prevalence.
  • NPV = TN / (TN + FN). Negative predictive value. Depends on prevalence.
  • Likelihood ratios are prevalence-independent. LR+ = sensitivity / (1 − specificity).
  • ROC curve — plots sensitivity vs (1 − specificity) across thresholds. AUC = 0.5 useless, 1.0 perfect.

16. Common MCQ Traps

  1. "p < 0.05 means H₀ is false" — WRONG. p is conditional on H₀ being true. It does not give the probability of H₀.
  2. "Statistical significance = clinical importance" — WRONG. Tiny effects can be significant with huge n.
  3. "Cohort = retrospective; case-control = prospective" — REVERSED in many textbooks. Cohort can be either; case-control is always retrospective (start with the outcome and look back).
  4. Confusing OR and RR — OR ≈ RR only when outcome is rare (< 10%). For common outcomes, OR overstates RR.
  5. Sensitivity vs Specificity confusion — Sensitivity uses people who HAVE disease (column with disease); Specificity uses people who DON'T.
  6. SD vs SEM — SD describes data spread; SEM describes precision of the mean. SEM is always smaller. Researchers sometimes use SEM to make data look prettier — be skeptical.
  7. Type I vs Type II — α = false positive (reject true H₀). β = false negative (miss real effect). "Sigh, I missed it" = II.
  8. "Random sampling = random assignment" — DIFFERENT. Random sampling is about who gets in the study (external validity). Random assignment is about which group they go in (internal validity).
  9. "r = 0 means no relationship" — only for linear relationship. A perfect U-shaped curve has r ≈ 0.
  10. "ANOVA tells you which group differs" — NO. ANOVA only tells you at least one differs. Use post-hoc (Tukey, Bonferroni) for pairwise.
  11. Cross-sectional and causation — cannot establish causation because temporality is unclear.
  12. "Convenience sample is fine if n is large" — NO. Bias doesn't reduce with sample size. A large biased sample is precisely biased.
  13. Fisher's exact vs Chi-square — Fisher's when expected cell count < 5 in any cell of a 2×2 table.
  14. Wilcoxon signed-rank vs Mann-Whitney U — Signed-rank for paired/related; Mann-Whitney for independent groups.
  15. One-tailed test "for more power" — only justified if effect direction is theoretically locked in advance. Otherwise it's p-hacking.
  16. "Random assignment controls for everything" — only on average and only if n is large. Small RCTs can still have unbalanced groups by chance.
  17. Kappa cutoffs — <0 worse than chance, 0-0.20 slight, 0.21-0.40 fair, 0.41-0.60 moderate, 0.61-0.80 substantial, 0.81-1.00 almost perfect (Landis & Koch 1977).
  18. Mediator vs Moderator — Mediator explains how (mechanism). Moderator changes when/for whom (conditions).
  19. Regression to the mean — extreme scores naturally drift toward the mean on retest. A common confound in pre/post designs without a control group.
  20. Hawthorne effect — being observed changes behavior. Threat to internal validity.
  21. Demand characteristics — participants guess and conform to the hypothesis.
  22. Experimenter / Rosenthal effect — researcher's expectations bias the results. Solved by double-blinding.

Memorization Hooks

  • NOIR levels of measurement: Nominal, Ordinal, Interval, Ratio.
  • "Sigh, I missed it" = Type II error.
  • Cohort = "future", Case-control = "past".
  • SnNout, SpPin — Sensitive test, Negative result rules OUT; Specific test, Positive result rules IN.
  • Mediator = how; Moderator = for whom / when.
  • 0.2 / 0.5 / 0.8 — Cohen's d small / medium / large.
  • 0.10 / 0.30 / 0.50 — Pearson r small / medium / large.
  • Belmont 3: Respect, Beneficence, Justice.
  • RCT phases I→II→III→IV: safety → efficacy → confirmation → surveillance.
  • Power = 1 − β. Aim for 0.80 (β = 0.20).
