1. Approaches to human cognition

ApproachWhoWhat it is
Experimental cognitive psychology—Studies cognition in healthy people via lab experiments (RT, accuracy); the oldest strand.
Cognitive neuropsychology—Studies brain-damaged patients to infer normal architecture; assumes modularity (functions are separable).
Cognitive neuroscience—Uses fMRI, PET, EEG/ERP, TMS to locate cognition in the brain (where and when).
Computational cognitive science—Builds computer models that simulate cognition; includes connectionism / parallel distributed processing.
Information-processing approachBroadbent (founding)The mind as stages of input → processing → output; the frame the whole book sits in.
Bottom-up vs top-down runs through the whole book. Bottom-up (data-driven) = processing starts from the stimulus. Top-down (concept-driven) = expectations, context and stored knowledge shape it. Almost every debate below is "how much of each."

2. Visual perception

Theory / termWhoWhat it is
Constructivist theoryRichard GregoryPerception is top-down: we build (construct) percepts by inference from incomplete data; explains illusions as wrong hypotheses.
Direct perception / ecological theoryJames GibsonPerception is bottom-up: the rich optic array directly affords meaning, no inference needed ("affordances").
Computational theory (primal/2½-D/3-D sketch)David MarrVision builds up in stages from edges to a viewer-centred (2½-D) then object-centred (3-D) representation.
Gestalt grouping lawsWertheimer, Koffka, KöhlerProximity, similarity, closure, continuity, common fate, Prägnanz; "the whole is other than the sum of parts."
Depth cues—Binocular (retinal disparity, convergence) + monocular/pictorial (linear perspective, interposition, texture gradient, motion parallax).
Perceptual constancies—Size, shape, colour, brightness stay stable despite changing retinal image.
Two visual systems (perception vs action)Milner & GoodaleVentral stream "what" (perception/recognition) vs dorsal stream "where/how" (visually guided action). Patient DF = damaged ventral.
Gregory vs Gibson: Gregory = indirect/constructivist, top-down, perception is a hypothesis (great for illusions, poor light). Gibson = direct, bottom-up, info is in the array (great for rich real-world viewing). If the stem says "inference / hypothesis," it's Gregory; "affordance / optic array," it's Gibson.

3. Object & face recognition

Theory / termWhoWhat it is
Template theory—Match input to a stored whole template; fails on size/orientation/font variation.
Feature theory / PandemoniumSelfridgeRecognise by detecting component features ("demons" shout for the features they see).
Recognition-by-components (geons)Irving BiedermanObjects decomposed into ~36 basic 3-D shapes (geons); view-invariant recognition.
Face recognition modelBruce & YoungSeparate routes: structural encoding → face recognition units → person identity nodes → name. Familiarity can come before the name.
Prosopagnosia—Selective inability to recognise faces despite intact object recognition; ventral/fusiform damage (FFA).
Visual agnosiaLissauer (apperceptive vs associative)Can't recognise objects despite intact vision. Apperceptive = can't form the percept; associative = percept formed but can't link it to meaning.
Apperceptive vs associative agnosia: apperceptive can't copy the drawing (perception broken); associative can copy it but still can't say what it is (perception intact, meaning lost).

4. Attention

ModelWhoWhat it is
Filter (early-selection) theoryDonald BroadbentOne channel; an early filter selects by physical features before meaning. Basis of dichotic listening.
Attenuation theoryAnne TreismanUnattended channel is turned down, not off; salient words (your name) still get through. Early but leaky filter.
Late-selection theoryDeutsch & Deutsch (extended by Norman)All input is processed for meaning; selection happens late, at response.
Capacity / resource theoryDaniel KahnemanAttention is a limited pool of effort allocated flexibly; explains dual-task interference.
Spotlight / zoom-lensPosner; EriksenVisual attention is a movable spotlight that can narrow or widen; Posner cueing measures it.
Feature Integration TheoryAnne TreismanFeatures (colour, shape) detected in parallel pre-attentively; attention is the "glue" that binds them into objects. Explains illusory conjunctions; pop-out vs serial search.
Inattentional / change blindnessSimons & Chabris; RensinkWe miss the unexpected gorilla / the swapped person when attention is elsewhere.
Automatic vs controlled processingShiffrin & SchneiderAutomatic = fast, parallel, no capacity (Stroop interference); controlled = slow, serial, effortful.
Early vs late selection: Broadbent = filter before meaning (early). Treisman = attenuate, not block (early but leaky). Deutsch-Norman = process everything, select at response (late). The cocktail-party "you hear your own name" finding kills strict Broadbent and fits Treisman.

5. Short-term & working memory

Model / termWhoWhat it is
Multi-store modelAtkinson & ShiffrinSensory store → STM → LTM, linked by attention and rehearsal. The serial-position curve (primacy = LTM, recency = STM) supports it.
Sensory memory (iconic / echoic)Sperling (iconic)Very brief, large-capacity modality store; partial-report shows iconic memory ~1/2 s, echoic ~2–4 s.
Magic number 7 ± 2George MillerSTM holds ~7 chunks; capacity is set by chunks, not raw items, so chunking expands it.
Working memory modelBaddeley & HitchReplaces unitary STM: central executive + phonological loop + visuospatial sketchpad (+ episodic buffer, added later).
Phonological loopBaddeleyInner voice + inner ear; word-length & phonological-similarity effects, articulatory suppression.
Episodic bufferBaddeley (2000)Limited store that binds info across systems into a unified episode, links to LTM.
Levels of processingCraik & LockhartDeeper (semantic) encoding → better retention than shallow (structural/phonemic); memory is a by-product of processing depth.
Multi-store vs working memory: Atkinson-Shiffrin's STM is a single passive store; Baddeley-Hitch splits it into active components doing different jobs. Evidence for the split: you can do a verbal + visuospatial task at once but not two verbal tasks (separate subsystems).

6. Long-term memory

TermWhoWhat it is
Declarative vs proceduralCohen & SquireDeclarative (explicit, "knowing that") vs procedural (implicit, "knowing how," skills).
Episodic vs semanticEndel TulvingEpisodic = events tied to time/place ("my last birthday"); semantic = general facts ("Paris is the capital"). Both declarative.
Encoding specificity principleTulving & ThomsonRetrieval is best when cues at recall match cues at encoding (basis of context- and state-dependent memory).
Forgetting curveHermann EbbinghausSteep early loss then levelling; pioneered nonsense syllables and savings method.
Reconstructive memory / schemaFrederic Bartlett"War of the Ghosts": recall is rebuilt to fit schemas, so it distorts toward the familiar.
ConsolidationMüller & Pilzecker; McGaughNew memories are fragile and stabilise over time; sleep and the hippocampus aid it.
Patient H.M.Scoville & MilnerBilateral medial-temporal/hippocampal removal → dense anterograde amnesia but intact STM and procedural learning. Proof STM and LTM dissociate.
Episodic vs semantic: if the fact is tied to when/where you learned it, episodic; if it's free-floating general knowledge, semantic. Amnesics often lose episodic while semantic survives.
Anterograde vs retrograde amnesia: anterograde = can't form new memories after the injury (H.M.); retrograde = lost memories from before the injury.

7. Forgetting & everyday memory

TermWhoWhat it is
Decay theory—Memory trace fades with time if not used.
Interference theory—Proactive = old learning blocks new; retroactive = new learning blocks old.
Cue-dependent forgettingTulvingThe trace is intact but the retrieval cue is missing (tip-of-the-tongue).
Repression / motivated forgettingFreudThreatening memories pushed out of awareness (controversial).
Misinformation effectElizabeth LoftusPost-event misleading info reshapes eyewitness memory ("smashed" vs "hit" changes the speed estimate).
Flashbulb memoryBrown & KulikVivid, confident memory of a shocking event; vivid does not mean accurate.
Weapon focusLoftusA weapon draws attention and narrows it, worsening memory for the rest of the scene.
Prospective memory—Remembering to do something in the future (event- vs time-based), distinct from retrospective memory.

8. Concepts & knowledge representation

Theory / termWhoWhat it is
Defining-attribute (classical) view—A concept = a set of necessary & sufficient features; fails for fuzzy categories.
Prototype theoryEleanor RoschWe judge category membership by similarity to a best/average example; basic-level categories & typicality effects ("robin" is a better bird than "penguin").
Exemplar theoryMedin & SchafferWe store specific instances, not an average; categorise by similarity to remembered exemplars.
Hierarchical semantic networkCollins & QuillianConcepts in a tree with cognitive economy; predicts sentence-verification times by distance.
Spreading activationCollins & LoftusConcepts linked by relatedness, not strict hierarchy; activation spreads → semantic priming.
Schema / scriptBartlett; Schank & Abelson (scripts)Organised knowledge packets that guide comprehension and inference (the "restaurant script").
Prototype vs exemplar: prototype = one abstracted average per category; exemplar = many stored individual instances. "Compare to the ideal bird" = prototype; "compare to all the birds I've seen" = exemplar.

9. Language

Theory / termWhoWhat it is
Linguistic relativity (Whorf hypothesis)Sapir & WhorfLanguage shapes thought; strong (determinism) form rejected, weak (influence) form has some support.
Language acquisition device / universal grammarNoam ChomskyInnate grammar; surface vs deep structure; transformational grammar. Against Skinner's behaviourist account.
Garden-path modelFrazier (minimal attachment)We parse a sentence one way and have to reanalyse ("The horse raced past the barn fell").
Dual-route model of readingColtheartLexical route (whole-word, for irregular words) + grapheme-phoneme route (sounding out). Surface vs phonological dyslexia map onto the two routes.
Speech production modelWillem LeveltConceptualisation → formulation → articulation; speech errors (Spoonerisms, slips) reveal the stages.
Categorical perception / McGurk effectMcGurk & MacDonaldVision changes what speech sound you hear (see "ga," hear "ba" → perceive "da"); speech perception is multimodal.
Cohort modelMarslen-WilsonSpoken word recognition: all words matching the onset activate, then narrow as more sound arrives.
Broca's aphasiaPaul BrocaNon-fluent, effortful, agrammatic speech; comprehension relatively spared. Lesion: left frontal.
Wernicke's aphasiaCarl WernickeFluent but meaningless "word salad," poor comprehension. Lesion: left temporal.
Broca vs Wernicke: Broca = Broken speech, can't produce, but understands (frontal). Wernicke = fluent nonsense, can't comprehend (temporal). Conduction aphasia = can't repeat (arcuate fasciculus).

10. Problem solving & expertise

Theory / termWhoWhat it is
Insight / restructuringGestalt (Köhler, Wertheimer)Sudden reorganisation of the problem ("aha"); Köhler's chimp Sultan stacking boxes.
Functional fixednessKarl DunckerFixating on an object's usual use blocks the solution (the candle / box-of-tacks problem).
Mental set (Einstellung)Abraham LuchinsA strategy that worked before is applied rigidly even when a simpler one exists (water-jar task).
Means–ends analysisNewell & SimonReduce the gap between current and goal state via subgoals; General Problem Solver, Tower of Hanoi.
Problem spaceNewell & SimonAll states + operators between start and goal; solving = searching this space.
Well- vs ill-defined problems—Well-defined have clear start/goal/operators (chess); ill-defined don't ("write a good essay").
Expertise & chunkingde Groot; Chase & SimonChess masters recall real board positions far better than novices, but not random ones, expertise = stored chunks, not raw memory.
Analogical problem solvingGick & HolyoakWe transfer a solution from a similar problem (radiation/fortress); surface similarity helps spot it.

11. Judgement & decision making

TermWhoWhat it is
Heuristics & biasesTversky & KahnemanAvailability (ease of recall), representativeness (resemblance to a prototype), anchoring & adjustment.
Base-rate neglectTversky & KahnemanIgnoring prior probabilities in favour of individuating detail (the "Tom W." / lawyer-engineer problem).
Conjunction fallacyTversky & KahnemanJudging "feminist bank teller" more likely than "bank teller" (the Linda problem); a conjunction can't exceed its parts.
Prospect theoryKahneman & TverskyWe value gains/losses from a reference point, not absolute wealth; losses loom larger (loss aversion); S-shaped value function.
Framing effectTversky & KahnemanThe same choice framed as a gain vs a loss flips preference (the "Asian disease" problem).
Bounded rationality / satisficingHerbert SimonLimited capacity → we settle for "good enough" rather than the optimal choice.
Dual-process theory (System 1 / 2)Stanovich & West; KahnemanSystem 1 = fast, automatic, intuitive; System 2 = slow, effortful, analytic.
Availability vs representativeness: availability = judging by how easily examples come to mind (overrate plane crashes). Representativeness = judging by how much it resembles the stereotype (Linda, Tom W.). The conjunction & base-rate fallacies both stem from representativeness.

12. Reasoning

TermWhoWhat it is
Deductive vs inductive—Deductive = certain conclusion from premises (syllogisms); inductive = probable generalisation from cases.
Wason selection taskPeter WasonThe 4-card logic test people fail abstractly but pass when framed as a familiar social rule (drinking-age version).
2-4-6 task / confirmation biasPeter WasonPeople test rules by seeking confirming, not falsifying, evidence.
Belief biasEvans, Barston & PollardWe accept invalid syllogisms whose conclusions we believe and reject valid ones we don't.
Mental models theoryPhilip Johnson-LairdWe reason by building mental models of possibilities; errors come from considering too few models.
Atmosphere effectWoodworth & SellsThe "mood" of the premises (some/all, no) biases which conclusion feels right in syllogisms.
Pragmatic reasoning schemasCheng & HolyoakWe reason with context-bound rules (permission, obligation), not pure logic; explains Wason content effects.
Wason's two tasks: the selection task (4 cards, P/not-P) tests conditional logic and is solved by familiar content. The 2-4-6 task tests hypothesis testing and exposes confirmation bias. Both are Wason, don't conflate them.
