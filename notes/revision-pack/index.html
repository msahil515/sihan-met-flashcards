Amino-acid → neurotransmitter pathway (PKU sits at step 1)

Your note: "DOnt know this. need to learn"
  • Phenylalanine → Tyrosine via phenylalanine hydroxylase (PAH). PKU = PAH broken. Phenylalanine piles up (brain-toxic), tyrosine drops, melanin drops (fair hair/skin), classic musty odour. Autosomal recessive. Treat: low-Phe diet for life.

  • Glutamate → GABA via GAD (B6 cofactor). Glutamate is the main excitatory NT; GABA is the main inhibitory NT. Benzos + alcohol potentiate GABA-A.

Wernicke-Korsakoff — one disease, two phases

Your note: "What is korsakoff, need to learn this"
  • Cause: thiamine (vit B1) deficiency. Classic context: chronic alcoholism (poor diet + reduced absorption + thiamine demand).
  • Wernicke encephalopathy (acute): triad of confusion + ophthalmoplegia + ataxia. Reversible if treated.
  • Critical rule: IV thiamine BEFORE glucose. Giving glucose first burns the last thiamine and precipitates Wernicke.
  • Korsakoff psychosis (chronic): anterograde amnesia + confabulation. Largely irreversible. Lesion = mammillary bodies + dorsomedial thalamus.
  • Memory aid: WAR + KAR. Wernicke = (W)hite-eyes + (A)taxia + confusion (R)eversible. Korsakoff = (K)onfabulation + (A)nterograde + (R)etrograde, ir(R)eversible.
  • Confabulation = false memories without intent to deceive. Distinguishes Korsakoff from malingering. Also in frontal lobe + ACoA aneurysm rupture.

Adrenaline vs noradrenaline + adrenal anatomy

Your note: "What about norepinephrine?"
  • Adrenal cortex (GFR = salt, sugar, sex). Outside → in: Zona Glomerulosa = aldosterone (mineralocorticoid); Zona Fasciculata = cortisol (glucocorticoid); Zona Reticularis = androgens (DHEA).
  • Adrenal medulla. Chromaffin cells = epinephrine (~80%) + norepinephrine (~20%). Directly innervated by sympathetic preganglionic fibres (skips the postganglionic step).
  • NE/Noradrenaline is also the postganglionic sympathetic NT at most target organs (heart, vessels, sweat except palms). E is the hormonal systemic arm of the same response.
  • HPA axis: hypothalamus CRH → anterior pituitary ACTH → adrenal cortex cortisol. Cortisol feeds back negatively to both. Dexamethasone suppression test = exogenous steroid that should shut down ACTH; non-suppression suggests Cushing's or pituitary tumour.

Splitting + BPD defenses + Vaillant hierarchy

Your note: "What is splitting?"

Splitting = inability to hold opposing qualities (good + bad) about the same person at the same time. Person experienced as all-good (idealised) one moment, all-bad (devalued) the next. Targets flip rapidly, often mid-session. Kernberg identified it as core defense in BPD; Klein first described it in early infancy (paranoid-schizoid position).

priorityn1_thr04

Ellis vs Beck — the dividing line

You picked Beck on a "musterbation" question on the mock. The two are easy to swap. Trigger-words:

  • Ellis — REBT (1955). ABC model (Activating event → Belief → Consequence) + Dispute + Effective new philosophy. Targets irrational beliefs, especially "musts / shoulds / oughts" (musterbation), awfulizing, catastrophising, low-frustration-tolerance, global self-rating. Confrontational style.
  • Beck — Cognitive Therapy (1960s). Cognitive triad in depression: negative view of self / world / future. Targets automatic thoughts, cognitive distortions, schemas. Collaborative empiricism, Socratic.
  • Beck's distortions: all-or-nothing, overgeneralisation, mental filter, disqualifying the positive, jumping to conclusions (mind-reading + fortune-telling), magnification / minimisation, emotional reasoning, "should" statements, labelling, personalisation.
Trigger words. "Musterbation / ABC / irrational belief / disputation" → Ellis. "Cognitive triad / schema / automatic thought / cognitive distortion" → Beck.

CBT waves. 1st-wave = behaviour therapy (Wolpe, Skinner). 2nd-wave = cognitive (Ellis, Beck, Meichenbaum). 3rd-wave = DBT (Linehan, Zen-rooted), ACT (Hayes), MBCT (Segal/Williams/Teasdale), MBSR (Kabat-Zinn).

Logotherapy + existential family

Your note: "Need more info on this"
  • Viktor Frankl (1905-1997). Austrian psychiatrist + Holocaust survivor. Built Logotherapy = "third Viennese school" (after Freud + Adler). Book: Man's Search for Meaning (1946).

Ego-dystonic vs ego-syntonic

  • Ego-dystonic = experienced as alien / unwanted / not me.
  • Ego-syntonic = experienced as consistent with self / "this is who I am".
  • OCD obsessions are ego-dystonic → insight preserved, patient fights the thought, distressed. Not the same as "poor insight" (DSM-5 specifier).
  • Personality disorders are typically ego-syntonic → patient doesn't see traits as a problem → poor insight + poor treatment-seeking.

OCD high-yield (NIMHANS recurring)

  • DSM-5: OCD moved out of anxiety into own chapter "Obsessive-Compulsive and Related Disorders" (with BDD, hoarding, trichotillomania, excoriation).
  • Treatment: SSRIs (high dose, 10-12 wks trial), clomipramine (TCA, serotonergic), ERP (Exposure and Response Prevention) = gold standard psychotherapy.
  • Neurobiology: CSTC loop (cortico-striato-thalamo-cortical), hyperactive OFC + caudate.
  • Insight specifiers: good/fair, poor, absent/delusional.

Delusional misidentification four-pack + extras

  • Othello syndrome: delusion that spouse is unfaithful. Strong link to alcohol-use disorder + IPV.

Schizophrenia theorists (this is a 2023 + 2024 NIMHANS repeat)

  • Kraepelin (1893): "dementia praecox" = early-onset deteriorating psychosis. Distinguished from "manic-depressive insanity" (now bipolar). The Kraepelinian dichotomy = foundation of modern nosology.
  • Bleuler (1908): renamed it schizophrenia ("splitting of mind"). 4 As: Association (loose), Affect (flat), Ambivalence, Autism (withdrawal). "Fundamental" vs "accessory" symptoms.
  • Schneider (1959): first-rank symptoms: thought insertion / withdrawal / broadcasting, audible thoughts, voices commenting / arguing, somatic passivity, delusional perception. Used in ICD-10; ICD-11 dropped emphasis.
  • Crow: Type I (positive sx, drug-responsive) vs Type II (negative sx, treatment-resistant). Outdated.
  • Andreasen + Carpenter: positive / negative / disorganised dimensions.

Factor analysis basics (you flagged this completely)

Your note: "Dont know anything about this"
  • Kaiser-Guttman rule: retain factors with eigenvalue > 1.0. Eigenvalue = variance explained by a factor in standardised units. >1 means the factor explains more variance than a single observed variable would.
  • Scree plot (Cattell): plot eigenvalues against factor number. Find the "elbow" where the line flattens. Keep factors above the elbow.
  • EFA (exploratory): no a-priori structure, let data tell you. Common in scale development.
  • CFA (confirmatory): you have a model, test it. Uses SEM.
  • Rotation: orthogonal (varimax) = factors stay uncorrelated. Oblique (promax, oblimin) = factors allowed to correlate. Psych constructs usually correlate.
  • Loading: correlation of an item with a factor. ≥0.30 = weak, ≥0.40 = moderate, ≥0.50 = strong.
  • PCA vs FA: PCA = data reduction, total variance. FA = latent structure, common variance.

Weber / Fechner / Stevens + signal detection

  • Weber's Law (1834): ΔI / I = k. JND is a constant fraction of original intensity. In a room with 1 candle, adding 1 is obvious; in a room with 100, you need ~10.
  • Fechner's Law (1860): Sensation = k × log(intensity). Subjective magnitude grows as the log of physical intensity.
  • Stevens' Power Law (1957): Sensation = k × (intensity)a. Different exponents per modality (brightness ~0.33, length ~1.0, electric shock ~3.5).
  • Psychophysics methods (Fechner): method of limits, method of constant stimuli, method of adjustment.
  • Signal detection theory (Green & Swets): d' = sensitivity (separates signal from noise). β / c = response criterion (bias). 4 outcomes: hit, miss, false alarm, correct rejection.

Marshmallow Test + Mischel hot/cool

Your note: "Briefly explain this to me"
  • Mischel (Stanford, 1960s-70s): 3-5 year olds offered 1 marshmallow now or 2 if they waited ~15 min. Outcome = wait time. Follow-ups (Mischel & Shoda): waiting predicted SAT, BMI, social competence, self-regulation in adolescence + adulthood.
  • Mechanism: waiters used cognitive strategies (look away, distract, reframe marshmallow as "cloud not food"). Basis of hot/cool system: hot = limbic, impulsive; cool = prefrontal, regulatory.
  • Replication caveat: Watts, Duncan & Quan (2018) found effects shrink substantially when family SES is controlled. Paradigm is real, deterministic narrative is overstated.
  • Connects to: executive function (Diamond), self-regulation (Rothbart), delay aversion in ADHD (Sonuga-Barke).

Exam-day execution rules

  1. Underline NOT / EXCEPT / LEAST / ALL in the stem before reading options. Half your "knew it but got it wrong" misses are negation-blindness. Cost the same as not knowing the answer.
  2. If 3 options agree and 1 disagrees on an antonym / "NOT" question, the outlier is usually the answer. Read the relationship in the stem (synonym? antonym? part-whole? cause-effect?) before scanning options.
  3. Eliminate options with extreme words on RC main-idea questions: "every, always, never, all, none, only, must." Pick the most general statement the passage actually supports.
  4. Hedging language ("can," "may," "in some cases," "a range of") → tone is "supportive but qualified," not absolute.
  5. If the stem names ICD, give ICD durations. If DSM, give DSM. If unspecified on NIMHANS, default to ICD.
  6. For trigger-word school attribution: "musterbation / ABC / irrational" → Ellis. "Cognitive triad / schema / automatic thought" → Beck. "Empty chair / here-and-now" → Perls / Gestalt. "Therapeutic community" → Maxwell Jones. "Logotherapy / will to meaning" → Frankl. "Zen + mindfulness for BPD" → Linehan / DBT.
  7. Don't guess on biostats unless the four-row table (RR/OR/HR/NNT) is firm. Your mock-1 numbers had you guessing 4-5 of 10 biostats Qs — that's a coin flip for ~20% of NIMHANS marks.
  8. Marathon pacing: 100 Qs / 90 min = 54 sec/Q. If a question takes >90 sec, mark + skip. Come back if time allows. Most NIMHANS papers reward speed over deliberation on individual items.
  9. Last 5 minutes: never leave a blank. Negative marking is for wrong answers, not blanks — but a blind guess across 4 options still has +25% expected value if there's no -ve mark, and zero if there is. Know your paper's policy.
