2. Descriptive Statistics

Central tendency

  • Mean — arithmetic average. Pulled by outliers.
  • Median — middle value. Robust to outliers, best for skewed data.
  • Mode — most frequent. Only measure for nominal data.

Dispersion

  • Range = max − min.
  • IQR = Q3 − Q1. Used in box plots.
  • Variance (σ²) = mean of squared deviations.
  • Standard deviation (σ) = √variance. Same units as data.
  • SEM = σ / √n. SD of the sampling distribution of the mean.

Shape

  • Skewness: positive (right tail; mean > median > mode), negative (left tail; mean < median < mode), zero (symmetric).
  • Kurtosis: leptokurtic (peaked), mesokurtic (normal), platykurtic (flat).

The normal distribution (mock-1 Q6)

  • Symmetric, bell-shaped. Mean = median = mode.
  • Empirical rule: ±1 SD covers ≈ 68%; ±2 SD covers ≈ 95%; ±3 SD covers ≈ 99.7%.
  • z-score = (X − μ) / σ. Standardises any score.
  • T-score: M=50, SD=10. T=70 → +2 SD → 97.5th percentile (MMPI clinical cutoff).
  • Stanine: M=5, SD=2, range 1–9.
  • Sten: M=5.5, SD=2, range 1–10.

MCQ trap (mock-1 Q5): stratified divides population into strata then random samples within; cluster randomly picks groups then samples all or many units per cluster. Both are probability methods.

4. Hypothesis Testing

Setup

  • H0 (null) = no effect / no difference / status quo.
  • H1 (alternative) = effect exists. Two-tailed (any direction) vs one-tailed (specific direction).
  • α = type I error rate (false positive). Conventionally 0.05.
  • β = type II error rate (false negative).
  • Power = 1 − β. Conventionally ≥ 0.80.

Errors

H0 trueH0 false
Reject H0Type I (α, false +)Correct (power)
Retain H0CorrectType II (β, false −)

Mock-1 Q1 trap: Type I = wrongly rejecting a TRUE null. (Wrongly retaining a false null = Type II.)

p-value

  • Probability of obtaining the observed result or more extreme if H0 were true.
  • NOT the probability that H0 is true.
  • If p < α → reject H0 (mock-1 Q3: p=0.03 < α=0.05 → reject).
  • Statistically significant ≠ practically important. Always report effect size.

Power

  • Increases with: larger n, larger effect size, larger α, lower variability, one-tailed test.
  • A priori power analysis sets sample size before data collection.

Confidence intervals

  • 95% CI: if we repeated the study many times, 95% of intervals would contain the true parameter.
  • If 95% CI for a difference excludes 0 → significant at p < 0.05.

7. Non-Parametric Tests

Use when: ordinal data, small n, non-normal data, or violated assumptions.

  • Chi-square (χ²): categorical variables. Goodness-of-fit (one variable) or test of independence (two variables, contingency table). Assumption: expected count ≥ 5 per cell.
  • Fisher's exact test: like chi-square but for small expected counts (2×2 tables).
  • McNemar's test: paired categorical (e.g., before/after).
  • Mann-Whitney U: non-parametric independent two-sample (mock-1 Q2).
  • Wilcoxon signed-rank: non-parametric paired test.
  • Kruskal-Wallis: non-parametric one-way ANOVA.
  • Friedman: non-parametric repeated-measures ANOVA.
  • Spearman ρ / Kendall's τ: rank correlation.

8. Post-Hoc Tests (mock-1 Q8)

If ANOVA F is significant, the omnibus result tells you that at least one mean differs but not which. Post-hoc pairwise tests localise differences while controlling family-wise error rate.

9. Correlation + Regression

  • r ranges −1 to +1. 0 = no linear association. ±1 = perfect.
  • Mock-1 Q9 trap: r = +0.90 means a strong positive linear association. r² = 0.81 → 81% of variance explained (NOT 90%). Correlation does NOT imply causation.
  • Cohen's r benchmarks: 0.10 small, 0.30 medium, 0.50 large.
  • Linear regression: Y = a + bX + ε. Least-squares fit minimises sum of squared residuals.
  • Multiple regression: more predictors. Beware multicollinearity (VIF).
  • Logistic regression: binary outcome. Reports odds ratios.
  • Mediation (Baron-Kenny / Hayes PROCESS): X → M → Y.
  • Moderation: X × M interaction term in regression.

10. Reliability + Validity (Measurement)

Reliability (consistency)

  • Test-retest — same test, two times. Susceptible to memory.
  • Parallel forms — equivalent forms.
  • Split-half (Spearman-Brown corrected).
  • Internal consistency — Cronbach's α (≥0.7 acceptable; ≥0.8 good). KR-20 for dichotomous items.
  • Inter-rater — Cohen's κ (categorical), ICC (continuous).

Validity (accuracy)

  • Content — covers domain (face validity = informal subset).
  • Criterion — concurrent (now) vs predictive (future).
  • Construct — convergent (correlates with similar measures), discriminant (doesn't with unrelated). Includes factorial validity.

Validity ceiling: max validity = √reliability (assuming criterion is perfectly reliable). r_xx = 0.81 → max validity = 0.90.

11. Research Designs

Experimental hierarchy

DesignRandom assignment?Control group?Internal validity
True experimentYesYesHigh
Quasi-experimentNo (intact groups)YesModerate
Pre-experimentalNoOften noLow
Non-experimental (correlational)——No causation

Specific designs to know

  • Pretest-posttest control group — classic two-group RCT.
  • Posttest-only control group — avoids pretest sensitisation entirely.
  • Solomon four-group (mock-1 Q4) — combines both. Two groups get pretest, two don't, half each get treatment. Detects + separates pretest sensitisation (interaction of pretest and treatment) from the treatment effect itself. Resource-heavy but most rigorous.
  • Crossover design — every subject receives both conditions in different order.
  • Factorial design — 2+ IVs, allows interaction analysis.
  • Single-case (ABA, ABAB, multiple baseline) — used in behaviour analysis.
  • Cohort study — follow exposed and unexposed groups forward; reports relative risk.
  • Case-control — start with cases and controls, look back; reports odds ratio.
  • Cross-sectional — single point in time; reports prevalence.

Blinding: single (subject), double (subject + experimenter), triple (+ analyst). Reduces bias.

Allocation concealment ≠ blinding — concerns who knows the next assignment at the time of randomisation.

13. Threats to Validity

Internal validity (causation within study)

  • History — external events during study.
  • Maturation — natural change with time.
  • Testing — pretest affects posttest (controlled by Solomon four-group).
  • Instrumentation — measure changes mid-study.
  • Regression to the mean — extreme scorers move toward mean.
  • Selection bias — non-random group differences.
  • Mortality / attrition — differential dropout.
  • Diffusion of treatment — control group learns from experimental.
  • Hawthorne effect — being observed changes behaviour.
  • Demand characteristics — subjects guess hypothesis.

External validity (generalisation)

  • Population validity (sample → population).
  • Ecological validity (lab → real life).
  • Treatment variation, time of measurement, etc.

Construct + statistical conclusion

  • Construct: does the operationalisation match the construct?
  • Statistical conclusion: is the inference about the relationship valid? Threats: low power, violated assumptions, p-hacking.

15. Qualitative Methods (overview)

  • Phenomenology — lived experience (Husserl, Giorgi, IPA).
  • Grounded theory — Glaser-Strauss, theory built from data via constant comparison and theoretical sampling.
  • Ethnography — culture/community, participant observation.
  • Case study — in-depth single unit (Yin).
  • Narrative analysis — life stories.
  • Discourse / conversation analysis — language as social action.
  • Thematic analysis (Braun & Clarke) — flexible coding for themes.
  • Trustworthiness criteria (Lincoln-Guba): credibility, transferability, dependability, confirmability.
  • Triangulation — data, investigator, theory, methodological.

16. Ethics

  • Belmont Report (1979): respect for persons, beneficence, justice.
  • Informed consent — capacity, voluntariness, disclosure, comprehension.
  • IRB / Ethics Committee approval — required before data collection.
  • Confidentiality, anonymity, debriefing.
  • Special populations — children, prisoners, cognitively impaired, pregnant women.
  • Major scandals to know: Tuskegee, Milgram, Stanford Prison, Nazi experiments → Nuremberg Code (1947), Declaration of Helsinki (1964 onwards).
  • Indian context: ICMR National Ethical Guidelines (2017), New Drugs and Clinical Trials Rules (2019).

17. Mock-1 Trap Recap (10 questions)

  1. Type I error = wrongly rejecting a true null (false positive).
  2. Mann-Whitney U = non-parametric independent t-test.
  3. p < α → reject H0. p-value is NOT P(H0 true).
  4. Solomon four-group controls + measures pretest sensitisation.
  5. Cluster = random groups, sample within. Stratified = strata, random within each.
  6. Normal distribution: ±1 SD ≈ 68%.
  7. Cohen's d: 0.2 small, 0.5 medium, 0.8 large.
  8. Significant ANOVA → post-hoc (Tukey, Bonferroni) to localise.
  9. r = +0.90 = strong positive linear association; r² = 0.81 = 81% variance explained.
  10. CONSORT = RCT reporting. PRISMA = SR/meta. STARD = diagnostic. COREQ = qualitative.
