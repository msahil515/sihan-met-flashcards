How to use these tests

Working agreement, so the data is useful
Mocks, once a week
Sit one full-length on a Sunday morning, 120 min, no breaks, no notes. Then debrief every wrong with the matching cheatsheet on the same day.
Mixed bank, daily
20-30 questions a day, pick the section you're weakest on per the dashboard. Tag your guesses so the bank can show your real, non-fluked accuracy.
Backup before you switch device
Progress is local to this browser. Use the copy backup code button on each quiz before clearing data or switching device.
