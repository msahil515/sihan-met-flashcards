One place that holds everything. Backbone last synced 2026-06-13.

How this works

Your database is one Google Drive folder — “Mphil Clinical Psychology- Mimaansa”. Every PDF, paper, book and syllabus lives there permanently, so nothing is ever lost. This site reads from it. The page below is the front door: the same store, sorted by college and by type so you can actually find things.

Open the backbone folder →
Adding something to the database
  1. Drop the PDF into the Drive folder, or send it to me on WhatsApp.
  2. It gets filed under the right college and type (notes / mocks / syllabi / books).
  3. If it’s a paper, I turn it into a playable untimed mock and link it here.
  4. It shows up on this page and stays in the store forever.
