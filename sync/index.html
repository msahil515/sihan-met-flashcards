How to set it up, once

  1. On this device, hit Turn on sync. You get an 8-character code.
  2. Open this same page on the other device (phone or tablet) and type the code in the box. Same code = same history.
  3. That's it. From then on every mock you attempt syncs by itself: on page open, when you switch tabs, and every 90 seconds while you're on the site.

What gets synced

  • Every mock attempt, question by question, on both engines (the classic quiz pages and the new /take/ engine).
  • Snapshots and score history on My Results, so best scores and trends are one list, not two.
  • Your journal notes per mock, and per-question notes inside a mock.
  • Mark-done flags on the Tests page and the study-plan checklists.

It merges, it does not overwrite. If you answered Q12 on the tablet and Q40 on the phone, you end up with both. Only if the exact same question was answered differently on both does the later answer win. A sync never deletes an attempt.

The boring details

Your code never leaves the device. It gets hashed into a long random-looking slot name on a small free key-value host, and only that slot name goes over the wire. There's no account and no password, so treat the code like a house key: anyone who has it can see your results. It's mock scores, not bank details, but don't paste it in a group.

Sync needs internet. Attempts made offline sit safely on the device and go up the next time you open the site with signal. If the host is ever unreachable you lose nothing locally, and the manual backup code on My Results still works as an offline fallback.
