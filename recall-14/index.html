Formula sheet every one the drill uses

Spearman-Brown (Spearman, Brown, 1910) r_new = k·r / (1 + (k − 1)·r) split-half: r_full = 2r / (1 + r) length needed: k = r_t(1 − r) / (r(1 − r_t)) Halves must be parallel (equal means and variances). Unequal variances: it overestimates.
Rulon (1939) and Flanagan (1937) Rulon: r = 1 − σ²_d / σ²_x Flanagan: r = 2(1 − (σ²_a + σ²_b) / σ²_x) d = odd half minus even half. Already full length: never step up. No equal-variance assumption. Given SDs? Square them first.
KR-20 (Kuder and Richardson, 1937) KR-20 = (k / (k − 1))(1 − Σpq / σ²) item variance = pq, max .25 at p = .50 Right/wrong items, one trait, power test. Equals alpha when items are 0/1.
KR-21 and alpha (Cronbach, 1951) KR-21 = (k / (k − 1))(1 − M(k − M) / (k·σ²)) α = (k / (k − 1))(1 − Σσ²_i / σ²_x) KR-21 assumes equal difficulty, so it comes out lower than KR-20 when difficulties vary.
Speed tests Split-half in one sitting, KR-20, KR-21 and alpha are all spuriously high (near 1). Use test-retest, alternate forms, or two separately timed halves stepped up with Spearman-Brown.
Variance σ² = Σ(X − M)² / N = ΣX²/N − M² sample estimate: s² = SS / (N − 1) Add c: no change. Multiply by c: variance × c², SD × c.
SEM and attenuation (Spearman, 1904) SEM = SD·√(1 − r) r_true = r_xy / √(r_xx·r_yy) 95% band = ±1.96 SEM. Validity can never exceed √(reliability).
Linear vs non-linear Linear (shape kept): z, X − M, 50 + 10z. Non-linear (normalising, via percentiles): percentile ranks, stanines, stens, normalised or McCall's T. Stanines 1 to 9: 4, 7, 12, 17, 20, 17, 12, 7, 4 %.
