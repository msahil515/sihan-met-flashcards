    Exam-day rules

    Decided now, not on the day
    Skip rule
    90 min for 100 Q is under a minute each. If a Q runs past ~50 sec on first pass, flag it and move on. Time kills the score, not the hard question.
    Guess rule (+1 / −0.25)
    Negative marking is gentle. Guess if you can knock out even one of four (+0.5 expectancy). Only leave blank if all four look equally alive.
    Two passes
    Pass one: answer everything you know cold, flag the rest. Pass two: spend the leftover time only on flagged ones. Never read all 100 in order once.
